# Product Vision

**Annotix** is designed to be a world-class, **open-source, offline-first computer vision platform**.

Our goal is to provide researchers, data scientists, and ML engineers with a local-first alternative to expensive cloud platforms like Roboflow or CVAT, without sacrificing performance, aesthetics, or extensibility.

## Core Pillars
1. **Offline-First Privacy**: No cloud dependencies. All data and AI inference remain on the user's local machine.
2. **Infinite Extensibility**: A plugin-first architecture allowing custom AI models, custom exporters, and custom storage adapters.
3. **Enterprise Performance**: The capability to smoothly handle datasets with 100,000+ images without layout thrashing.
4. **Platform Agnostic Data**: Using Annotix Native Format (ANF) as a single source of truth, completely decoupled from YOLO, COCO, or VOC limitations.
